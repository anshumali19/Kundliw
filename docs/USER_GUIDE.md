# Maharshi Kanad Jyotish Kendra – Website User Guide
# महर्षि कणाद ज्योतिष केंद्र – वेबसाइट उपयोग गाइड

Site: https://kanadjyotishkendra.vercel.app  ·  Languages: Hindi (default) / English – switch with the **EN / हिं** button in the header.

---

## 1. For visitors and customers (ग्राहकों के लिए)

**Menu:** Home · Services · Booking · Matching · Kundli · Blog · Contact. On a phone, use the bottom bar: Home, Menu, Package, Booking, Offer, Login.

| What you want | Where to go |
|---|---|
| See all astrology services and prices | **Services** |
| Book a consultation (pick service, date, time, pay) | **Booking** |
| Check Kundli match for marriage | **Matching** |
| Make your Kundli (birth chart) | **Kundli** |
| Current offers | **Offer** (bottom bar) |
| Certificates (GST, MSME, Trademark, ISO) – view, download, print | Footer → **Credentials** |
| Find the office on the map, call or message | **Contact** (map also in the footer) |
| Quick help | Floating buttons: Call, WhatsApp (left) · AI Chat, Chat (right) |

**Sign in / register:** Login → choose *User*. You can use mobile OTP, email + password or Google. After signing in use the menu (your name) → **Logout** to sign out.

**Upload your Kundli:** My Documents (Vault) → *Upload*. Any of PDF, image, video, audio, Word, Excel, PowerPoint, text (up to 4 MB). Your file appears in a preview window next to the upload button. PDFs, images, video, audio and text open in the page; Word/Excel files show a Download button. Only you and the Kendra can open your files.

**Marquee (scrolling notice):** it pauses when you point at it; press **×** to close it.

---

## 2. For associates (सहयोगी / एसोसिएट)

1. Register as *Associate* (or log in at *Associate* portal with password / Google).
2. Wait for approval if the Kendra has turned auto-approval off.
3. Copy your **referral link/code** from your dashboard and share it. A visitor who books through it is remembered for the number of days the Kendra has set.
4. Dashboard shows referrals, commission (Pending → Earned → Paid) and payout history.
5. Fill **Payout details** (UPI and/or bank account + IFSC) so you can be paid.
6. Request a **payout** once your earned amount reaches the minimum set by the Kendra.

---

## 3. For the Super Admin (मुख्य प्रशासक)

Sign in at the *Super Admin* portal (email/mobile + password, or OTP). Use **Admin** in the menu.

| Area | What you can do |
|---|---|
| Services, Plans, Offers, Slots | Add, edit, activate/deactivate, remove. Use content blocks (text, image, YouTube, link). |
| Orders / Appointments | See bookings, change status, upload reports to a customer. |
| Associates | Approve/reject, set personal commission, add notes, see payout details, handle payouts. |
| **Associate settings** | Switch the programme on/off, auto-approve, minimum payout, referral validity days, commission rules, terms (Hindi/English). |
| Vault | View and upload files for any customer. |
| **Credentials** | Upload GST, MSME, Trademark, ISO documents with title/number; hide, edit or delete. Visitors can view, download, print. |
| **Marquee** | Text (Hindi/English), speed, font size, text colour, background colour, position; choose *pause on hover* and *allow close*. |
| Settings → **Location Map** | Change the Kendra's location any time: latitude/longitude, zoom, label, or paste a Google Maps embed code. Switch the map on/off. |
| **Backup Manager** | *Back up now*; automatic daily copy (plus weekly on Sundays, monthly on the 1st); choose how many copies to keep; download any copy (a readable JSON without passwords or secrets). |
| Blog, Banners, Gallery, Testimonials, FAQ, Pages | Edit site content. |
| Chatbot | Add question/answer pairs; AI answers the rest. |

**Restoring from a backup:** copies are for safety and can be downloaded. Restoring is done by the developer on request.

---

## 4. Good to know

- Uploads are limited to **4 MB** per file.
- The Google sign-in button works once the Kendra's Google keys are added to the hosting settings; until then they say "not switched on yet" and password/OTP login still works.
- Keep your password private; log out on shared phones.

*Support: contact the developer for changes or restore requests.*

## 5. What is new in the admin panel (Oct 2026)

- **Left menu, grouped:** Overview · Bookings & money · People · Website · System. On a phone it folds into one "Admin menu" button.
- **Website settings** (Website group): social media links (Active/Hide), logo, home page strip, hero text, SEO, features on/off, Panchang / Kundli / Matching pages on/off, mobile app links, analytics.
- **Promo codes:** each code can be limited to chosen services, a minimum order, a total number of uses and a number of uses per customer. Customers see the exact reason when a code does not apply.
- **Google Analytics:** paste the Measurement ID in *API keys & Analytics*. See `docs/FREE_AND_PAID_SERVICES.md`.
- **Date bar:** the top line shows time, day, date, month, paksha, tithi and Vikram Samvat automatically.
